# 🍳 RecipeBook - Recipe Book with Categories

RecipeBook is a personal recipe management web application built using HTML, CSS and JavaScript.

Users can add, edit, delete, search and categorize recipes. All recipes are stored locally using the browser's LocalStorage.

## 🚀 Features

- Add new recipes
- Edit existing recipes
- Delete recipes
- Delete confirmation
- Recipe categories
- Category filtering
- Search recipes
- Recipe detail view
- Cooking time
- Ingredients
- Cooking instructions
- Recipe image
- LocalStorage persistence
- Responsive design
- Modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Array.filter()

## 📁 Project Structure

recipe-book/
│
├── index.html
├── style.css
├── script.js
└── README.md

## ▶️ How to Run

1. Download or clone this project.
2. Open the project folder.
3. Double-click `index.html`.

Or open the folder in VS Code and use the Live Server extension.

## 💾 LocalStorage

Recipes are stored inside the browser using:

localStorage.setItem()

The application loads the saved recipes using:

localStorage.getItem()

Therefore, recipes remain available after refreshing the page.

## 📌 Categories

The application supports:

- Breakfast
- Lunch
- Dinner
- Dessert
- Snacks
- Drinks
